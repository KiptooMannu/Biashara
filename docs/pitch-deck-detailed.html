The problem

MSMEs are underserved by software that is either too basic or too expensive.

Fragmented tools

Stock, till, books, customers and suppliers live in different places. A simple business question turns into a spreadsheet exercise.

Reports, not decisions

Most products tell an owner what happened. Very few tell them why it happened, what it cost, and what should happen next.

Middle of the market is empty

Spreadsheets are too manual and enterprise suites are too heavy, costly and slow to implement.

The real pain is not data entry. It is the gap between a transaction and an action. A missed stockout, a delayed payment, or a slow-moving SKU all create hidden losses that no current tool makes obvious.

Differentiator

The AI assistant is grounded in live business data.

What it does

  • Classifies the user’s business question by intent
  • Runs the right analytics queries against the live database
  • Composes an answer from those numbers and shows the evidence behind it

Why it matters

Instead of producing a generic summary, the assistant can say, “gross profit is up, expenses rose, and stock availability is the short-term risk.” That is usable advice, not language-model fluff.

The assistant is intentionally not a black-box LLM. It is built to be auditable: every answer returns the figures used and the query source, so a business owner can verify the recommendation before acting.

Architecture

Designed as a modular monolith with the boundaries already drawn.

Backend

Spring Boot 3.5, Java 21 bytecode on JDK 25, Spring Security, Spring Data JPA, Hibernate 6.6.

Frontend

React 18, TypeScript, Vite 6, Tailwind CSS and shadcn/ui components.

Data layer

Neon serverless PostgreSQL with shared-schema multi-tenancy and tenant-aware entities.

Execution model

Bounded contexts are packaged separately under the application, so the future split into services is a lift, not a rewrite.

Security and trust

Permission-based access control is enforced, not just styled.

Authorization model

  • 63 permissions in a catalogue
  • Roles are database-defined bundles of permissions
  • Endpoints enforce their own authority checks

What that means in practice

  • A cashier sees a reduced UI and is still denied finance routes
  • An HR manager cannot create a Business Owner
  • A role can be created at runtime without a redeploy

The product also includes audit trail, sign-in history, forced password changes for first-login users and secure token handling with refresh rotation.
